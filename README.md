# Columbia Asia Hospital Analytics

## Project Overview

An interactive Power BI hospital analytics project developed to provide data-driven insights into hospital operations, patient behavior, doctor performance, revenue, waiting time, and patient satisfaction.

## Business Objective

The objective of this project was to analyze hospital data and provide actionable insights to support:

- Hospital performance monitoring
- Doctor performance analysis
- Patient and demographic analysis
- Revenue analysis
- Waiting time and satisfaction analysis
- Staffing and operational decisions

## Tools & Technologies

- Power BI
- SQL
- Excel
- DAX
- Power Query

## Dashboard

The project includes three interactive Power BI dashboards:

- **Main Dashboard** – Hospital-wide performance and KPI monitoring
- **Doctors Dashboard** – Doctor performance and revenue analysis
- **Patients Dashboard** – Patient demographics, visits, waiting time, and satisfaction analysis

## Key Insights

- Orthopedics generated the highest departmental revenue.
- General Practice recorded the highest patient volume.
- Patients aged 36–60 formed the largest patient group.
- Neurology recorded the highest average waiting time.
- Patient satisfaction showed a slight decline as waiting time increased.
- Revenue showed a gradual declining trend during the analyzed period.
- Patient distribution remained relatively balanced across genders.

## Recommendations

- Prioritize staffing based on patient demand and waiting time.
- Optimize appointment scheduling to reduce waiting time.
- Monitor patient satisfaction alongside service performance.
- Strengthen high-revenue departments while improving lower-revenue departments.
- Use targeted discount strategies for relevant patient segments.
- Track operational and revenue KPIs regularly.
